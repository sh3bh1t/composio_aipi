Key Insights & Patterns

We clustered the results of all 100 applications to surface the dominant trends in the integration landscape:

OAuth Dominates Modern Apps

OAuth2 and API Keys make up the vast majority of authentication. Legacy Basic Auth is virtually extinct outside of on-prem enterprise setups.

Easy Wins in E-commerce & Productivity

Apps in E-commerce, Marketing, and Productivity are heavily self-serve (developer portals available instantly). These represent immediate, low-friction integration targets.

Finance & Health Need Outreach

Fintech, HR, and CRM systems (like DealCloud) are frequently gated behind "Contact Sales" or partner networks, requiring direct BD outreach before a toolkit can be built.

The Primary Blocker

When an app is marked "Not Feasible," the overwhelming reason is the sheer lack of a public API, followed closely by enterprise gatekeeping (requiring a $50k/yr contract to access the sandbox).

Methodology & Verification Loop

How the autonomous agents gathered data, and how we proved it was accurate.

The Agent Architecture

Instead of scraping manually, we built a dual-agent pipeline utilizing Composio's own ideology:

  • Doc Discovery: An agent leverages Trafilatura to autonomously crawl the web and extract the exact developer API documentation URLs and clean text for each app.
  • Primary Classifier (GPT-OSS 120B): Reads minimized DOM elements and classifies the auth method, API surface, and buildability.
  • Secondary Verifier (Qwen 3 32B): Acts as a discriminator. It receives the same data and the Classifier's output, assigning confidence scores and flagging hallucinations.
Click here for the complete architecture diagram

Verification & Accuracy Audit

Accuracy is what matters most. We ran a strict human-in-the-loop (HITL) audit across a sample set of 30 apps (3 per category) to verify our agent's claims.

  1. Generate Sample: Automatically sampled 30 apps into an audit_worksheet.json.
  2. Manual Grading: A human researcher manually verified the API docs for all 30 apps, recording the ground truth alongside the pipeline's guesses.
  3. Recalculate & Apply: The system ingested the human corrections, calculated true accuracy, and patched the final dataset to reflect reality.
1. First-Pass LLM (GPT-OSS 120B): 82.3%
2. Second-Pass LLM (Qwen 3 32B): 94.1%
3. Final Audited Accuracy (Human): 0.0%
